# 서비스 기획서: 오늘의 운세

## 1. 개요
- **서비스명**: 오늘의 운세
- **한 줄 소개**: 버튼 하나 누르면 오늘의 운세를 알려주는 웹앱

## 2. 타겟 사용자
- 아침에 가볍게 운세를 확인하고 싶은 사람

## 3. 핵심 기능 (In-Scope)
- **"운세 보기" 버튼 제공**: 버튼을 누르면 오늘의 운세 결과를 보여줍니다.
- **랜덤 운세 추첨**: 운세 문구는 랜덤으로 뽑힙니다.
- **당일 결과 유지**: 같은 날 다시 버튼을 누르면 동일한 운세가 나옵니다. (하루 동안 유지)

## 4. 제외 항목 (Out of Scope)
- 로그인 및 회원가입
- 생년월일 등 개인정보 입력
- 유료 결제 및 유료 기능
