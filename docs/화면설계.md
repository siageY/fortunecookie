# 화면 설계서: 오늘의 운세

## 1. 화면 개요
- **화면 수**: 단일 페이지 (Single Page)
- **화면 컨셉**: 밝고 귀여운 분위기, 모바일 중심의 반응형 UI
- **주요 흐름**: 상단 타이틀 -> 중앙 "운세 보기" 버튼 클릭 -> 버튼 하단에 결과 카드 노출

---

## 3. 영역별 상세 요소

### 1) 상단 타이틀
- **텍스트**: `오늘의 운세`
- **스타일**: 둥글둥글하고 친근한 폰트, 볼드 처리로 주목도 확보

### 2) 중앙 버튼 ("운세 보기")
- **역할**: 운세 추첨 트리거 (하루 1회 유지)
- **스타일**: 
  - 모바일 터치에 최적화된 큼직한 크기
  - 누르고 싶어지는 입체감(부드러운 그림자 및 라운드 코너)

### 3) 결과 카드
- 버튼 하단에 부드럽게 나타나는 카드 형태
- **포함 요소**:
  1. **운세 등급 뱃지**: 대길, 길, 보통, 조심 (등급별 배경색 구분)
  2. **운세 문구**: 메인 메시지 (한 문장, 큰 폰트)
  3. **오늘의 조언**: 보조 설명 문구 (한 문장)
  4. **행운의 아이템**: 아이콘 또는 강조 텍스트와 함께 표시

## 4. 등급별 색상 제안 (밝고 귀여운 톤)

| 등급 | 테마 컬러 | HEX 코드 예시 | 느낌 및 설명 |
| :--- | :--- | :--- | :--- |
| **대길** | 화사한 코랄/골드 오렌지 | `#FF6B6B` / `#FFA94D` | 축제처럼 기분 좋고 매우 행운이 넘치는 따뜻한 느낌 |
| **길** | 산뜻한 클로버 그린 | `#51CF66` | 기분 좋은 하루를 암시하는 싱그럽고 편안한 느낌 |
| **보통** | 맑은 스카이 블루 | `#4DABF7` | 잔잔하고 평온한 일상을 나타내는 차분한 느낌 |
| **조심** | 소프트 퍼플 / 라벤더 | `#9775FA` | 무섭거나 불길하지 않고 귀엽고 재치 있게 주의를 주는 느낌 |

---

## 5. 반응형/모바일 고려사항
- 모바일 가로 너비 기준 최대 420px 내외의 카드형 뷰포트 권장
- 한 손으로 조작하기 편리하도록 중앙 버튼의 높이와 여백을 충분히 확보
